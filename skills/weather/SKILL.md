# /weather スキル

引数で渡された都市名の今日の天気を調べて報告するスキルです。

## 使い方

```
/weather 東京
/weather 大阪
/weather Tokyo
```

## 動作内容

1. 引数から都市名を取得する（未指定の場合は「東京」をデフォルトにする）
2. WebSearch ツールを使って「{都市名} 今日の天気 {今日の日付}」を検索する
3. 検索結果から天気・気温・降水確率を抽出する
4. 以下の形式で返答する：

```
🌤 {都市名} の今日の天気

天気：{晴れ/曇り/雨など}
気温：{最高気温}℃ / {最低気温}℃
降水確率：{%}

{一言コメント（服装など）}
```

## 注意

- 天気情報は WebSearch を使ったリアルタイム検索のため、検索結果がない場合は「情報を取得できませんでした」と返す
