# 評価軸（雛形）

`~/.claude/rules/common/evaluation-axes.md` に置いて使う。
`worklog` / `worklog-review` / `council`（Role-Evaluator）が読む。**無ければその機能はスキップされる。**

自分が実際に評価されている軸、あるいは自分で落としたくない線を書く。
下の5つは**書き方のサンプル**であって、そのまま使うものではない。

| ID | 軸 | できている状態 |
|---|---|---|
| F1 | 初期完成度 | 最初に出すものがレビュー前提でない。手戻り・修正往復を減らす |
| F2 | 逆算スケジュール | 期日から逆算した工程を持ち、期日内にクローズする |
| F3 | 自己評価の精度 | 役割の期待範囲内のことを加点扱いしない |
| F4 | やりきり | 依頼を人に頼らず完遂し、依頼水準を満たしてから出す |
| F5 | 波及 | 自分の効率化で止めず、チームの仕組みに定着させる |

## 書くときの注意

- **軸は3〜6個に絞る。** 多いと Role-Evaluator の指摘が散って使えなくなる
- **「できている状態」を観察できる形で書く。**「意識する」「気をつける」は判定できないので避ける
- **ID（F1 形式）を必ず振る。** スキルが `key_concern` にこの ID を入れて返す

## 使われ方

- `worklog` — 当日のエントリに該当する軸 ID を付ける
- `worklog-review` — 期末の下書きで軸ごとの振り返りを生成する
- `council` — Role-Evaluator が案件の**進め方**だけを見て、該当した軸を指摘する
  （案件そのものの良し悪しは他の9ロールが見る）
